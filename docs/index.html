Features

Everything the default launcher skips

RailStrap sits between Windows and Roblox, adding quality-of-life features without touching how the game itself runs — and without a ban risk, since it never interacts with the client the way exploits do.

Custom loading screen

A video splash plays while Roblox boots instead of a blank window — bring your own, muted and looped automatically.

Ping overlay & server hop

Live connection ping shown in-game, plus reroll into a fresh server instantly without leaving and rejoining by hand.

Auto-restart on crash

If Roblox crashes unexpectedly, RailStrap relaunches it for you.

FastFlag presets

One-click toggles for uncapped FPS, MSAA and texture quality — no manual config editing.

Studio plugin manager

Browse, disable and remove installed Roblox Studio plugins from one place.

Theme & mod gallery

Install community bootstrapper themes and content mods directly from RailStrap, or build your own with the built-in editor — no manual file wrangling.

Friend activity panel

Optional and off by default. See what friends are playing using your own Roblox cookie — encrypted on-device, never uploaded anywhere.

Discord Rich Presence

Let friends see what you're playing at a glance, with server-join support.

Playtime stats

A private, local log of your play sessions per game — nothing leaves your PC.

In-app log viewer & import/export

Search Roblox's log output without leaving RailStrap, and back up or move your settings in one click.

Install

Up and running in about a minute

1

Download the latest release from the GitHub Releases page.

2

Run the installer. RailStrap ships unsigned, so SmartScreen may warn — click "More info", then "Run anyway".

3

Install the .NET 6 Desktop Runtime if prompted — RailStrap needs it to run.

4

Configure your preferences and finish setup. RailStrap is then available from your Start Menu.

No ban risk. RailStrap only wraps the launch process — it doesn't interact with the Roblox client the way exploits do.

Privacy

Nothing leaves your PC by default

RailStrap is fully open source, so every claim below is verifiable directly in the code.

No telemetry by default

Analytics are disabled out of the box. RailStrap doesn't phone home or report usage data anywhere.

Local-only credentials

The optional friend activity cookie is encrypted on-device with Windows DPAPI, and only ever sent directly to Roblox's own API.

Everything stays local

Playtime stats, settings, and logs live in your user profile. Nothing is uploaded to us.

Open source

Full source is public on GitHub, so anyone can audit exactly what RailStrap does.

Help

Common issues

Quick fixes for the most frequent problems.

Roblox won't launch, or the download fails+

Usually antivirus or firewall software blocking RailStrap from reaching Roblox's servers. Temporarily allow it through your firewall/antivirus and try again.

RailStrap crashes or won't open+

Try reinstalling the latest release. If that doesn't help, delete %LocalAppData%\RailStrap to reset your configuration, then reinstall.

Windows SmartScreen is blocking the installer+

Expected — RailStrap ships unsigned. Click "More info", then "Run anyway".

Discord Rich Presence isn't showing up+

Make sure Activity Tracking and Discord Rich Presence are both enabled in Integrations settings, and Discord is running before you launch Roblox.

Still stuck?+

Open an issue on GitHub Issues — RailStrap's crash/error dialogs can generate a pre-filled report for you.
